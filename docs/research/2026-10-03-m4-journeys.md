## How they were developed

Five rounds on the base builds (runs 37139054732, 37139594634, 37140040580, 37140786020, 37141599755). Rounds 1 and 2 ran in the NVDA-absent leg only; rounds 3–5 ran in both legs. Each journey ran once per round. The runner records, per step, every goal attempt's target (the focused or cursor node, or NVDA's speech). Anchors and goals were taken from those traces and from the recorded accessibility trees, never from a candidate. Round 5: every journey completes on its base build in both legs, with all 32 attempts valid.

| Round | Finding | Fix |
|---|---|---|
| 1 | Playwright's clock API also fakes `performance.now()` and rAF, so every Atomic CRM attempt was INCONCLUSIVE | A Date-only shim (P14; DR-0069) |
| 1 | The simulated cursor kept its last browse position after focus moved | The cursor follows focus (DR-0069) |
| 1 | The desktop contact page has no tabs | The tab journey moved to the company page (DR-0069) |
| 2 | A full page load mid-journey looked like clock drift | One page clock per document, as HANDOFF §7.3 asks (DR-0069) |
| 3 | NVDA reads a list item as one line; it speaks "/" as "slash"; its first Escape in a menu leaves focus mode; it stays in focus mode after a form | The line model, punctuation-free goals, Escape twice, Escape before heading navigation (DR-0070) |
| 4 | NVDA's cursor is at the bottom of a page after an in-app navigation; in browse mode, Space clicks a drag handle | DOCUMENT_TOP and FOCUS_MODE_TOGGLE (P26; DR-0071) |

## Principles

- A goal names what the item's regression does not change, so the regression shows in an expectation rather than as an UNREACHABLE step. The exceptions are patterns whose symptom is reachability (NAV_TARGET_UNREACHABLE, JOURNEY_BLOCKED) (DR-0068).
- A journey does what a keyboard user of that leg would do. In the NVDA-present leg, that includes NVDA's own needs: pressing Escape twice in a menu, switching to focus mode for a drag, going to the top of a new page. These steps are harmless in the NVDA-absent leg.
- An element without an accessible name is identified by its DOM id in expectations (`#id`), which is B2's identity (P12).
