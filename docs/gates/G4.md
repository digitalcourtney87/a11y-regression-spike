## 10. Risks

- **77 is the pre-registered size.** The dev power table's C-versus-B2 adjudicated row estimated 155 patterns. PROTOCOL §3 follows 77 and does not resize from these counts.
- **The difference interval is outside the frozen renderer.** Putting it into the scorer now would amend a frozen path after this split was scored. This report is the record of the statistic. An amendment can wait until the second-round tree is tagged, and it has to say that these intervals had already been seen.
- **The dev rule choice is tied.** With B2 detecting every dev regression item, rule 1 wins by being earliest. The test metric is the residual, which is why the tie does not get re-decided here.
- **Frozen limits still bound two readings.** NVDA cannot see the Vuetify dialog pull-back or the Fluent list-item role on the base. Bootstrap speech that is silent after Escape is KEYBOARD_TRAP, while the tree says FOCUS_NOT_RESTORED when focus moved. Those limits were ratified at G3 (DR-0089).
